# Frontend

React 19 + Vite UI for Edu LLM: Ask (chat), Library (faculty workspaces, classrooms, slides, quizzes) and the
student view (docs, quizzes, assignments).

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build in dist/
npm run lint
```

Set `VITE_API_BASE_URL` if the backend isn't at `http://localhost:8000`.
